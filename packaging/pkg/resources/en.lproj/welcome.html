Secrets out of .env files.

Your projects keep references like latchkey://shop/production/DATABASE_URL. Latchkey keeps the values in iCloud Keychain and fills them in when a command starts.

Asks before it shares
Touch ID, with the program, folder and command that’s asking. Allow once, or a folder for a while.

Made for coding agents
An agent gets only what you’ve allowed, and values it prints are hidden.

On every Mac you use
End-to-end encrypted in iCloud Keychain, on each Mac signed in to your Apple Account.

What happens next

  1. Latchkey is installed in Applications. You’ll be asked for an administrator password once.
  2. The latchkey command, and lk for short, are linked in ~/.local/bin.
  3. When the Installer closes, Latchkey opens a short welcome: the Safari extension, your coding agent and your first .env file, each only if you want them.

Latchkey needs macOS @MIN_OS@ or later. Values go only to the commands and services you approve.

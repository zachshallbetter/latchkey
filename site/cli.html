Command line

The command-line tool

latchkey, and lk for short, runs your commands with values filled in from Latchkey, and works with coding agents. Every value it asks for is approved in the Latchkey app.

With the Mac App Store version

An App Store app can't install tools outside its own folder, so the command-line tool is a separate, free download, signed by Snack Studio and notarized by Apple. Install it with Homebrew:

Or download latchkey-cli-VERSION.zip from the latest release, unzip it, move latchkey to a folder on your PATH (such as ~/.local/bin), and add lk as a link to it if you like.

Open Latchkey once, then check the tool reaches it:

With the direct download

The tool comes inside the app. Choose Latchkey › Install Command Line Tool…, which links ~/.local/bin/latchkey and lk to it, or install the app with Homebrew (brew install --cask latchkey), which adds both.

Pistachio is the new name for Pistachio. The current download, pst commands and pistachio:// references still use the original names.

Command line

The command-line tool

pistachio, and pst for short, runs your commands with values filled in from Pistachio, and works with coding agents. Every value it asks for is approved in the Pistachio app.

With the Mac App Store version

An App Store app can't install tools outside its own folder, so the command-line tool is a separate, free download, signed by Snack Studio and notarized by Apple. Install it with Homebrew:

Or download latchkey-cli-VERSION.zip from the latest release, unzip it, move pistachio to a folder on your PATH (such as ~/.local/bin), and add pst as a link to it if you like.

Open Pistachio (the current download) once, then check the tool reaches it:

With the direct download

The tool comes inside the app. Choose Pistachio › Install Command Line Tool…, which links ~/.local/bin/pistachio and pst to it, or install the app with Homebrew (brew install --cask latchkey), which adds both.

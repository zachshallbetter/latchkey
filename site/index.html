API keys for commands and coding agents on your Mac

Latchkey keeps API keys and database URLs in iCloud Keychain. When a command starts, it fills them in, after you approve with Touch ID or under a limit you set ahead of time. Your project files keep only references.

Move the values out of your env files

Point Latchkey at an env file. Each value goes into iCloud Keychain under the repository's name and the environment the file name implies, and the file keeps a reference in its place. If a file of references is committed by mistake, only the names show.

For every project at once, lk import --scan ~/Projects --dry-run lists each env file it found and where each value would go, before anything is sent.

Run commands with the keys filled in

Put lk run in front of a command. It reads the references, asks the app for the values, and starts the command with them in its environment. A value of six characters or more that the command prints shows up as <concealed by latchkey>. With --env, no file is needed at all, which suits a fresh git worktree that has no .env.

When an agent asks

The panel in the picture above appears on your Mac whenever a key isn't already allowed. Everything it shows comes from macOS rather than from the request: the program and the programs that started it, the folder it runs in, and its full command line. A script that talks to Latchkey directly, instead of through the signed lk tool, is named by its path with a warning.

Allow Once releases the keys for that run. To let an agent work while you're away, allow the folder for a while, until the agent quits, or only for one command. The same limits are available ahead of time:

Through the MCP server, an agent can ask for a grant only on its own folder and for its own session, for a day at most, and never for production items.

Keys an agent can use without reading

A command that has a key in its environment can print it, encode it or send it somewhere, and masking only catches exact copies. For OpenAI and Anthropic keys, lk run --proxy keeps the key out of the command. The command gets a placeholder and a base URL on your Mac; Latchkey adds the real key to requests bound for api.openai.com or api.anthropic.com and refuses everything else.

For AWS, lk run --aws-session gives the command credentials from STS that expire after 15 minutes, while your long-lived key stays in Latchkey.

After an agent session

lk touched lists every key Latchkey released to programs the agent started. lk rotate walks through them one by one. It ends the grants that cover them, opens each service's page for making a new key, saves what you paste with the old value kept in history, and pushes the new value to any Vercel, GitHub Actions, Railway or Fly environment it's linked to.

How it protects keys, and where it stops

Values live in iCloud Keychain in an access group only the signed Latchkey app can read, and sync end to end encrypted to each Mac signed in to your Apple Account that has Latchkey installed. The lk tool checks the app's code signature before sending anything, and the app checks the tool's. Grants are kept where only Latchkey can change them. The access log records every release, change and refusal without values, and chains each entry to the last, so lk log --verify notices an entry that was edited or removed.

Latchkey can't help with these:

  • A command you allowed has the key, and Latchkey can't control what it does with it. --proxy is the exception, for OpenAI and Anthropic.
  • Any program running under your account can ask. Keep grants narrow, and deny requests you don't recognize.
  • Someone with your Apple Account and a trusted device can reach iCloud Keychain.

Projects and environments

History
The last 10 values of each item, and deleted items for 30 days.
Remote locations
Link an environment to Vercel, GitHub Actions, Railway or Fly, check what's missing, and push with each service's own tool. Production needs a second confirmation.
MCP server
lk mcp lets an agent list items, check what a run would get, run commands and ask for a grant. It never returns a value.
Another Mac over SSH
Forward the app's socket with ssh -R; every request from the other Mac asks you here.

Install

  1. Download the disk image, open it, and drag Latchkey to Applications.
  2. Open Latchkey, then choose Latchkey › Install Command Line Tool… to add latchkey and lk to ~/.local/bin.
  3. Run lk status. It should say storage: iCloud Keychain.

Support and troubleshooting

Most answers are in the docs. For anything else, write to Contact support; we answer by email.

Start here

  • Quickstart: install, import an env file and run a command.
  • The command-line tool: getting it with the Mac App Store version or the direct download.
  • CLI reference and Agents and MCP.
  • pst status shows whether the command-line tool reaches the app, how you approve, and where values are kept. Include its output when you write (it never shows values).

Common problems

  • "cannot reach the Pistachio app" (exit 69): the tool starts Pistachio itself, so this usually means PISTACHIO_NO_LAUNCH=1 is set or the app can't start. Open Pistachio once and try again. It stays in the menu bar after you close its window, and keeps answering the tool.
  • A command still sees pistachio:// references: run it through pst run -- …, which replaces them with values for that command only.
  • Values don't appear on another Mac: both Macs need iCloud Keychain turned on with the same Apple Account, and the items must have been saved to iCloud Keychain. Syncing to a second Mac hasn't been tested end to end yet.

Pistachio Pro

Pro isn't on sale yet. When it is, it's bought in the Mac App Store. To unlock it on another Mac, sign in with the same Apple Account and choose Restore Purchases in Pistachio's Settings. Refunds go through Apple at reportaproblem.apple.com.

Report a mistake on this site

If a page says something Pistachio doesn't do, or leaves out a limit, email Contact support with the page and what's wrong, or open an issue. Corrections are listed in the changelog.

Report a security issue

Please don't post it publicly. Email Contact support with "Security" in the subject, the Pistachio and macOS versions, what an attacker can do and what they need first, and steps to reproduce with example values only. Never send a real secret. Security explains what's in scope.

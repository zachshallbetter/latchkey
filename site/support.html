Support

Support

Most answers are in the docs. For anything else, write to latchkey@snackstud.io; we answer by email.

Start here

  • Quickstart: install, import an env file and run a command.
  • CLI reference and Agents and MCP.
  • latchkey status shows whether the command-line tool reaches the app, how you approve, and where values are kept. Include its output when you write (it never shows values).

Common problems

  • "Latchkey isn't running" from the command-line tool: open Latchkey once. It stays in the menu bar after you close its window, and keeps answering the tool.
  • A command still sees latchkey:// references: run it through lk run -- …, which replaces them with values for that command only.
  • Values don't appear on another Mac: both Macs need iCloud Keychain turned on with the same Apple Account, and the items must have been saved to iCloud Keychain.

Latchkey Pro

Pro isn't on sale yet. When it is, it's bought in the Mac App Store. To unlock it on another Mac, sign in with the same Apple Account and choose Restore Purchases in Latchkey's Settings. Refunds go through Apple at reportaproblem.apple.com.

Report a mistake on this site

If a page says something Latchkey doesn't do, or leaves out a limit, email latchkey@snackstud.io with the page and what's wrong, or open an issue. Corrections are listed in the changelog.

Report a security issue

Please don't post it publicly. Email latchkey@snackstud.io with "Security" in the subject, the Latchkey and macOS versions, what an attacker can do and what they need first, and steps to reproduce with example values only. Never send a real secret. Security explains what's in scope.

Latchkey for Safari

Checking for Latchkey…

When one of these shows you a new API key, Latchkey offers to save it:

  • Stripe: Developers › API keys
  • OpenAI: API keys
  • Anthropic: Console › API keys
  • GitHub: Settings › Developer settings › tokens

If Safari shows a warning on this button, allow Latchkey on that site: Safari › Settings › Websites › Latchkey. It can't read the keys already in Latchkey.
